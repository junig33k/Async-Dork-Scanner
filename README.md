# Async-Dork-Scanner 🚀

[English]
An asynchronous dork scanning utility designed to automate web reconnaissance and identify potential SQL injection entry points. Built for security researchers to streamline target identification.

[Português]
Uma ferramenta assíncrona de varredura de dorks projetada para automatizar o reconhecimento web e identificar potenciais pontos de entrada de SQL injection. Desenvolvida para pesquisadores de segurança otimizarem a identificação de alvos.

## Usage / Uso
```bash
git clone [https://github.com/junig33k/Async-Dork-Scanner.git](https://github.com/junig33k/Async-Dork-Scanner.git)
cd Async-Dork-Scanner
python scanner.py
